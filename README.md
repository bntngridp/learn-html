# Learn HTML

Kumpulan kode latihan pembelajaran HTML yang dipisahkan dari repositori `mayyaisbetter/learn-frontend`.

## Struktur Materi

- `belajar-html-dasar/` - Pengenalan elemen dasar HTML, heading, paragraf, list, link, gambar, audio, video, tabel, semantic HTML, dan lainnya.
- `belajar-html-form/` - Pembuatan dan pengelolaan elemen form HTML (input, label, select, textarea, checkbox, radio, button, dan tipe input HTML5).

## Cara Menjalankan

Buka langsung berkas `.html` yang diinginkan melalui browser atau gunakan ekstensi Live Server pada editor kode.
